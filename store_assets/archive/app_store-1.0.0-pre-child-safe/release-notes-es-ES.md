# Mi Paga 1.0.0 — Novedades

- Crea perfiles gestionados por madres o padres para tareas, registros de paga
  y objetivos de ahorro.
- Conecta el teléfono o tableta de un menor mediante un código QR, enlace
  seguro o código de vinculación.
- Los menores pueden seguir su objetivo y solicitar una retirada para que la
  apruebe una persona adulta.
- Usa la app cómodamente en teléfonos compactos y pantallas plegables.
- Elige tu país y utiliza el nombre local para la paga.
