# App Store screenshots — 1.0.1

Use iPhone 17 Pro Max captures only. They must be clean captures from the
actual 1.0.1 Flutter screens with `ADS_ENABLED=false`, synthetic names and
amounts, no test-ad creative, no real account, and no simulator chrome.

## Required set per localization

1. Parent chores and review.
2. Parent money records and savings controls.
3. Child tasks.
4. Child money categories.
5. Child savings goal, including the parent-discussion explanation and no
   payout or money-request control.

Maintain a matching set for `en-US` and `es-419`. `es-ES` may reuse the
Spanish visual composition only after each visible term is reviewed for the
Spain localization.

The archived 1.0.0 captures are not eligible for upload because they were made
before the child-safe product boundary was finalized.
