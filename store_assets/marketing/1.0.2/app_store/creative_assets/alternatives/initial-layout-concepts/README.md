# Google Ads / Google Play promotion assets — 1.0.2

Prepared artwork for the **Header** and **Search Results** upload fields shown in Google’s campaign asset library.

## Ready-to-upload assets

| Placement | Size | English | Spanish (Latin America) | Spanish (Spain) |
| --- | --- | --- | --- | --- |
| Header | 5244 × 2950 px | `header-en-US-5244x2950.png` | `header-es-419-5244x2950.png` | `header-es-ES-5244x2950.png` |
| Search Results | 3840 × 1646 px | `search-results-en-US-3840x1646.png` | `search-results-es-419-3840x1646.png` | `search-results-es-ES-3840x1646.png` |

Each creative uses the real ChoreJar jar and app icon from the project plus an original abstract background layer. All visible copy is composed locally with the supplied Nunito font so it stays sharp and accurate.

## Copy by market

- **en-US:** ChoreJar — *Small chores. Big dreams.*
- **es-419:** Mi Mesadita — *Pequeñas tareas. Grandes sueños.*
- **es-ES:** Mi Paga — *Pequeñas tareas. Grandes sueños.*

The creatives promote chores, goals and savings without suggesting that a child can make payments. They do not show advertising, a subscription offer, personal data, or a live balance.

## Upload order

1. In the asset library, select **Header** and upload the matching `header-…` file.
2. Select **Search Results** and upload the matching `search-results-…` file.
3. Assign the asset to the market whose language matches the copy.
4. Use the English asset as the default if the console does not support localized creative assignment.

`source/abstract-green-gold-background.png` is retained as the non-product background layer used in both final graphics.
