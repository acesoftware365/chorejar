# Marketing assets — 1.0.2

This release folder contains prepared, localized artwork for the next ChoreJar / Mi Mesadita / Mi Paga release.

## App Store Connect

- Final Header and Search Results assets: [`app_store/creative_assets/`](app_store/creative_assets/)
- Each final asset has English (`en-US`), Latin American Spanish (`es-419`), and Spanish for Spain (`es-ES`) copy.
- Final files are separated by their Apple placements and dimensions. The detailed upload guide is in the creative-assets README.

These are promotional creative assets, not app screenshots. They use only project-owned brand artwork and generic marketing copy; they show no personal, financial, advertising, or subscription data.
