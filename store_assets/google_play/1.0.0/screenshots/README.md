# Google Play screenshots — 1.0.0

Use device captures only. The required English and Spanish sets should each
show, in this order:

1. A parent assigns and reviews a chore.
2. A child submits a chore and sees their progress.
3. A child saves toward a goal or requests a withdrawal.
4. A parent reviews the money history.
5. A parent links a child by QR or code.

`candidates/en-US/01-welcome-iphone-17-pro-max.png` is a clean, real-device
welcome-screen candidate. It is not one of the five narrative listing shots;
use it as a visual reference or add it only after confirming the final signed
release behaves identically.

`candidates/es-419/01-bienvenida-iphone-16e.png` is its clean Spanish
equivalent from the normal application. It is also a reference candidate, not
a replacement for the required five-screen Spanish set.

The complete staged Spanish narrative is in `drafts/es-419/parent/` and
`drafts/es-419/child/`: five screens for each role, captured with only
synthetic content and no ads. Review the draft README before upload.

The same ten-screen parent/child narrative is available in English under
`drafts/en-US/parent/` and `drafts/en-US/child/`.

The capture must not show a test ad, a real email address, a pairing code, or
a child-identifying name. Keep the final installed version and country/locale
visible only when the store permits it. Do not use the development build's
`ChoreJar v1.0.0 (10)` banner label as a store screenshot.
