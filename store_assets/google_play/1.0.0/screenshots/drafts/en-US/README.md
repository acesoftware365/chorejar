# English store-art drafts — parent and child

This folder mirrors the Spanish capture plan with five screens per role:

1. Tasks awaiting action.
2. Delivery or task-review state.
3. Money and savings.
4. Goal progress and device settings/linking.
5. Task creation or the cash-out request confirmation.

The capture-only target renders the actual Flutter parent and child screens
with the synthetic profile `Alex`, ads disabled, and no Firebase or user
session. It contains no real email address, pairing code, test-ad creative, or
child data. Confirm the final signed-release behavior and each store's
accepted screenshot dimensions before upload.
